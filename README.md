## Featured Project: AstroSpectro

**AstroSpectro** is a modular pipeline for the analysis of stellar spectra, currently focused on LAMOST DR5 data.

The project explores how machine learning can support astrophysical interpretation through:

- automated spectral data handling;
- physically motivated feature extraction;
- stellar spectral classification;
- dimensionality reduction with PCA, UMAP, t-SNE, and autoencoders;
- anomaly detection and clustering;
- model interpretation with SHAP;
- scientific validation of learned structures.

Repository: [AstroSpectro](https://github.com/PhD-Brown/AstroSpectro)
